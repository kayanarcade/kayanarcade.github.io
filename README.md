# kayanarcade.github.io

The Kayan Arcade website, served by GitHub Pages at https://kayanarcade.github.io.

- `index.html`: home page, with Plushie Pile and its Google Play link
- `privacy.html`: Plushie Pile privacy policy (linked from the Play listing)
- `app-ads.txt`: AdMob's authorised-seller line (AdMob reads it from the site root)
